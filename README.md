# Pocket Meadow / 掌中自然

Pocket Meadow (掌中自然) is a cozy browser-based ecology mini game. Plant seeds, shape the habitat with water, rocks, and sunlight, welcome wildlife, and discover a growing nature journal.

The game runs entirely in the browser and saves progress locally on your device. It supports English and Chinese, sound controls, fullscreen play, and mobile devices.
